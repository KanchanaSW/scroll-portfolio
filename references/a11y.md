# Responsive and accessibility

One app. `gsap.matchMedia()` builds and kills the right variant. Do not ship a separate mobile route.

## matchMedia queries

```ts
const mm = gsap.matchMedia()

mm.add(
  {
    desktop: '(min-width: 768px) and (prefers-reduced-motion: no-preference)',
    reduce: '(prefers-reduced-motion: reduce)',
    mobile: '(max-width: 767px)',
  },
  (ctx) => {
    const { desktop, reduce, mobile } = ctx.conditions!
    if (desktop) {
      // pin + pan + zoom + containerAnimation + parallax
    }
    if (mobile && !reduce) {
      // no pin; vertical stack; light fade/slide on ScrollTrigger (vertical starts)
    }
    if (reduce) {
      // no Lenis easing (lerp 1); never build camera timeline; vertical document
    }
  },
)
```

`mobile` and `reduce` can both be true — `reduce` wins: no cinematic camera.

## Below 768px

Pinning fights iOS dynamic viewport height. Stack scenes in normal flow (`flex-col`, full width). Keep the same React scene components; pass `vertical`. Lighter `fromTo` opacity/y is allowed. Progress rail still jumps via `lenis.scrollTo(element)`.

## prefers-reduced-motion

Non-negotiable — a large share of macOS/iOS users have this on.

- Lenis `lerp: 1` (or skip Lenis entirely)
- Do not create pan/zoom timelines
- Flip: instant panel, no transform animation
- Counters: set final values, do not tween
- Custom cursor: off

## Semantics and focus

- Skip link as the first focusable: "Skip to content", targets `#summary` or `<main>`
- One `h1` (hero name). Scene titles are `h2`
- Flip panel: `role="dialog"`, `aria-modal="true"`, labelled by project name, focus trap, restore focus to the card on close
- Command palette: shadcn already handles listbox semantics
- Do not keyboard-trap the cinematic stage itself

## Print

`@media print`: hide canvas chrome (rail, cursor, palette, preloader), unpin, show a linear résumé from `portfolio` (identity, summary, experience, projects, education, contact). `Cmd+P` must yield a clean résumé, not nine widescreen frames.
