# Responsive and accessibility

One app. `gsap.matchMedia()` builds and kills the right variant. Do not ship a separate mobile route.

## matchMedia queries

```ts
const mm = gsap.matchMedia()

mm.add(
  {
    desktop: '(min-width: 768px) and (prefers-reduced-motion: no-preference)',
    reduce: '(prefers-reduced-motion: reduce)',
    mobile: '(max-width: 767px)',
  },
  (ctx) => {
    const { desktop, reduce, mobile } = ctx.conditions!
    if (desktop) {
      // pin graphic + measure index on ticker
    }
    if (mobile && !reduce) {
      // no pin (or short pin); stack graphic above steps; same measureActiveStep
    }
    if (reduce) {
      // Lenis lerp 1; NumberMorph snaps; Chart snaps marks; still one index owner
    }
  },
)
```

`mobile` and `reduce` can both be true — `reduce` wins: no tweens.

## Below 768px

Pinning a tall graphic fights iOS dynamic viewport height. Stack: graphic (static) then steps. Keep `useStepIndex` as the owner so the chart still tracks the step in view. Lighter fade on step prose is allowed.

## prefers-reduced-motion

- Lenis `lerp: 1`
- `NumberMorph`: set text to the target, no tween
- Chart: no mark interpolation; paint `view` immediately
- Pin may remain so the story is readable; motion is the issue, not the layout

## Semantics and focus

- Skip link first: "Skip to story", targets `#scrolly`
- One `h1` (title). Step kickers are `h2`
- Graphic is `<figure>` with `<figcaption>` from `chart.annotation`
- Steps are `<section>` with `aria-current="step"` on the active one
- Keyboard: `j` / `k` or arrows scroll to prev/next step via `lenis.scrollTo(el)`. Ignore when focus is in an input

## Print

`@media print`: unpin, hide skip/preloader, show title, dek, then each step's prose plus the headline number. Not a screenshot of the pinned SVG.
